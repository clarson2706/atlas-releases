# Atlas downloads

Installers and update files for Atlas, a private assistant that runs on your own computer.

- **Atlas-Setup-x.y.z.exe**: installer for Windows. Updates itself each time you open it.
- **Atlas-x.y.z-portable.exe**: a single file you can run from anywhere. It does not update itself.

Get the latest version from the [Releases page](../../releases/latest). On first run Atlas is locked until you add a free Gemini key under Connectors. Everything it saves stays on your computer.

This repository holds downloads only.
